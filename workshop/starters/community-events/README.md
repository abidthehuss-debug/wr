# Community Events Board

Not sure what to build? Use this ready-made workshop idea.

```text
Claude: /workshop workshop/starters/community-events
Codex:  $workshop workshop/starters/community-events
```

You'll build a small community events web app where people can:

- browse, search, and filter events;
- add and manage their own events;
- view online event times in a few timezones.

The AI will guide you through everything. You do not need to understand the
files in this folder before starting.
