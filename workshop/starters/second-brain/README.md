# Second Brain Lite

Build a personal AI knowledge system that remembers useful context across fresh
AI sessions.

You will:

- create your own simple memory vault;
- ask Claude or Codex questions about it;
- deliberately teach it new things to remember;
- optionally connect Gmail or Google Calendar;
- visually review your Second Brain with Lavish.

Start here:

```text
Claude: /workshop workshop/starters/second-brain
Codex:  $workshop workshop/starters/second-brain
```

You do not need to understand the upstream project or technical setup first.
The workshop agent will guide you.
